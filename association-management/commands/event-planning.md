# /event-planning

Plan and execute association events from concept to post-event analysis.

## Usage

```
/event-planning [event-type] [options]
```

## Arguments

- `event-type`: Type of event (annual-conference, regional-meeting, webinar, workshop, networking, gala, golf-outing, trade-show)
- `--scale`: Expected attendance (small <50, medium 50-200, large 200-1000, mega 1000+)
- `--format`: In-person, virtual, hybrid
- `--budget`: Budget range or constraints
- `--timeline`: Event date or planning horizon

## What This Command Does

Generate comprehensive event planning materials:

### 1. Event Concept & Goals

Define the event foundation:

**Purpose Statement**
- Primary objectives (education, networking, revenue, advocacy)
- Target outcomes with measurable KPIs
- Alignment with strategic plan

**Audience Definition**
- Primary attendee personas
- Secondary audiences (sponsors, speakers, media)
- Attendance targets by segment

**Value Proposition**
- Why attend this event?
- Differentiation from competitors
- Member vs. non-member value

### 2. Timeline & Milestones

Create detailed planning timeline:

**12+ Months Out** (for large events)
- Venue selection and contracts
- Date confirmation
- Budget development
- Theme/branding concepts

**9 Months Out**
- Speaker recruitment begins
- Sponsor prospectus development
- Marketing plan finalization
- Registration system setup

**6 Months Out**
- Program content finalization
- Early bird registration opens
- Sponsor sales active
- Vendor contracts

**3 Months Out**
- Full marketing push
- Speaker confirmations
- Logistics finalization
- Volunteer recruitment

**1 Month Out**
- Final registrations push
- Materials production
- Staff briefings
- Contingency planning

**Week Of**
- Final confirmations
- On-site setup
- Real-time communications

### 3. Budget Framework

Comprehensive budget template:

**Revenue Lines**
- Registration (tiered pricing)
- Sponsorships (levels and benefits)
- Exhibitor fees
- Advertising
- Ancillary revenue (merchandise, recordings)

**Expense Categories**
- Venue and F&B
- Speaker costs (fees, travel, honoraria)
- Technology (AV, streaming, app)
- Marketing and promotion
- Staff and contractor costs
- Materials and signage
- Insurance and permits
- Contingency (10-15%)

**Break-even Analysis**
- Fixed vs. variable costs
- Attendance scenarios (pessimistic, expected, optimistic)
- Pricing sensitivity

### 4. Program Development

**Session Planning**
- Keynote selection criteria
- Breakout track structure
- Workshop formats
- Networking session design
- Entertainment/social events

**Speaker Management**
- Call for proposals template
- Speaker guidelines and expectations
- AV requirements collection
- Presentation template
- Rehearsal schedule

**Attendee Experience**
- Registration flow
- Wayfinding and signage
- Mobile app features
- Accessibility accommodations
- Dietary considerations

### 5. Marketing Plan

**Campaign Timeline**
- Save the date
- Early bird promotion
- Regular registration
- Last chance push

**Channel Strategy**
- Email campaigns (frequency and segments)
- Social media calendar
- Website/landing page
- Partner promotions
- Media outreach

**Messaging Framework**
- Key messages by audience
- Testimonials and social proof
- FOMO elements
- Value reinforcement

### 6. Sponsorship Program

**Package Development**
- Tiered levels with clear benefits
- À la carte options
- Exclusive opportunities
- Pricing strategy

**Prospectus Content**
- Audience demographics
- Reach and engagement data
- Benefit descriptions
- Deadlines and requirements

### 7. Logistics Checklist

Comprehensive operational checklist:
- Venue requirements and layout
- Catering specifications
- AV and technology needs
- Registration desk setup
- Signage and wayfinding
- Photography/videography
- Security considerations
- Emergency procedures

### 8. Post-Event Framework

**Immediate (Within 1 Week)**
- Thank you communications
- Survey distribution
- Social media wrap-up
- Preliminary metrics

**Short-term (Within 1 Month)**
- Full financial reconciliation
- Survey analysis and report
- Speaker/sponsor feedback
- Debrief meeting

**Long-term**
- ROI analysis
- Lessons learned documentation
- Next year planning kickoff

## Best Practices Applied

- Attendee-centric experience design
- Inclusive and accessible planning
- Sustainable event practices
- Risk mitigation strategies
- Technology integration
- Data capture for future engagement

## Example

```
/event-planning annual-conference --scale=large --format=hybrid --budget="$500k-750k" --timeline="October 2025"
```

Generates complete planning framework for a large hybrid annual conference.
