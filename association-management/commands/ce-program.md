# /ce-program

Design and manage continuing education and professional development programs.

## Usage

```
/ce-program [program-type] [options]
```

## Arguments

- `program-type`: Type of program (certificate, certification, ce-credits, learning-path, micro-credential)
- `--topic`: Subject area or competency focus
- `--format`: Delivery format (online, in-person, hybrid, self-paced)
- `--duration`: Program length
- `--accreditation`: Accreditation body or requirements

## Example

```

```

Creates a comprehensive certification program design for a data privacy credential with hybrid delivery and ANSI accreditation alignment.
