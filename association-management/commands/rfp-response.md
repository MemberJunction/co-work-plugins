# /rfp-response

Develop compelling RFP responses and competitive proposals.

## Usage

```
/rfp-response [response-type] [options]
```

## Arguments

- `response-type`: Type of response (government-rfp, corporate-rfp, partnership-proposal, service-proposal, grant-rfp)
- `--opportunity`: Brief description of the opportunity
- `--deadline`: Submission deadline
- `--budget`: Budget range or constraints
- `--competition`: Known competitive landscape
