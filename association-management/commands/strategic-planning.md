# /strategic-planning

Facilitate strategic planning processes and document development.

## Usage

```
/strategic-planning [phase] [options]
```

## Arguments

- `phase`: Planning phase (full-process, environmental-scan, goal-setting, implementation, review)
- `--horizon`: Planning horizon (3-year, 5-year, 10-year)
- `--approach`: Planning approach (traditional, agile, scenario-based)
- `--focus`: Specific focus areas or priorities
- `--stakeholders`: Key stakeholder groups to engage

## What This Command Does

Guide and document strategic planning processes:

### 1. Planning Process Framework

**Preparation Phase**
- Planning timeline development
- Resource allocation
- Stakeholder identification
- Data gathering plan
- Facilitator selection (internal/external)

**Discovery Phase**
- Environmental scanning
- Stakeholder input
- Data analysis
- Current state assessment

**Direction Setting**
- Mission/vision review
- Strategic priorities
- Goal development
- Success metrics

**Implementation Planning**
- Action planning
- Resource allocation
- Accountability assignment
- Timeline development

**Execution & Monitoring**
- Implementation support
- Progress tracking
- Course correction
- Annual review

## Example

```
/strategic-planning full-process --horizon="5-year" --approach=agile --focus="membership growth, digital transformation, advocacy expansion" --stakeholders="members, board, staff, partners"
```

Facilitates a complete 5-year strategic planning process with agile approach, focused on three priority areas with comprehensive stakeholder engagement.
