# Metrics and Analytics

This skill provides comprehensive knowledge for measuring association performance, making data-driven decisions, and demonstrating organizational value.

## Measurement Culture

### Why Measure?
- Make informed decisions
- Demonstrate value
- Identify improvement opportunities
- Allocate resources effectively
- Benchmark against peers
- Track progress toward goals
- Communicate impact

### Data-Driven Decision Making
- Define questions first
- Gather relevant data
- Analyze objectively
- Consider context
- Make informed decisions
- Monitor outcomes
- Adjust as needed

### Measurement Challenges
- Data quality and availability
- Attribution complexity
- Resource constraints
- Analysis expertise
- Action gap (data to decisions)
- Over-measurement fatigue

**Pulse Surveys**
- Quick, frequent checks
- Single-topic focus
- Trend monitoring

### Survey Best Practices
- Clear objectives
- Appropriate length
- Tested questions
- Representative sample
- Incentive strategy
- Action planning

### Net Promoter Score (NPS)
"How likely are you to recommend [organization] to a colleague?"
- 0-6: Detractors
- 7-8: Passives
- 9-10: Promoters
- NPS = % Promoters - % Detractors
- Association benchmark: 30-50 is good

## Using Metrics Effectively

### Metric Selection
- Aligned with goals
- Actionable
- Measurable
- Meaningful
- Limited (avoid overload)

### Target Setting
- Benchmark-informed
- Stretch but achievable
- Clear timeline
- Responsibility assigned
- Progress tracked

### Metric Review Process
- Regular cadence
- Variance analysis
- Context consideration
- Action identification
- Accountability

### Avoiding Pitfalls
- Vanity metrics (look good, don't matter)
- Analysis paralysis
- Gaming metrics
- Ignoring qualitative
- Attribution overconfidence
- Short-term focus
